# Explaining-Uncanny-Text

This project implements a robust classifier designed to distinguish between human-written text and content generated by Large Language Models (LLMs). By integrating explainability tools, we aim to uncover the linguistic "fingerprints" of modern models like GPT-5.4.

## 📌 Project Overview
As LLMs evolve, their outputs increasingly mimic human proficiency, posing challenges for academic integrity and information authenticity. This project develops a **RoBERTa-based classifier** and utilizes Explainable AI (XAI) techniques to interpret how the model identifies machine-generated patterns.

### Key Features
* **Dataset Expansion**: Supplemented the HC3 (GPT-3.5) dataset with ~24k original samples generated via **GPT-5.4-mini**.
* **Linguistic Analysis**: Comparative study of text length and perplexity distributions between human and AI samples.
* **Explainability (XAI)**: Implementation of **SHAP**, **LIME**, and **Attention Head visualization** to identify key predictive tokens.

# 📊 Methodology

## 1. Data Processing

This project utilizes the **HC3-English dataset**. To evaluate the classifier against state-of-the-art models, a custom dataset of ~24,000 samples was generated using **GPT-5.4-mini**.

* **Word count constraints** were implemented to ensure the AI-generated text mirrors the length distribution of human responses, preventing the model from relying on text length as a primary classification feature.

## 2. Modeling

The core of the detection system is a **fine-tuned RoBERTa-base model**. The architecture is optimized for binary classification:

* **Label 0:** Human-generated text
* **Label 1:** AI-generated text

## 3. Explainability & Analysis

To provide transparency into the model's predictions, several **Interpretability (XAI) techniques** are integrated:

* **SHAP & LIME:** Visualize token-level importance and identify which specific words trigger an "AI" classification.
* **Attention Analysis:** Map the transformer attention heads to see how the model processes syntactic structures unique to LLMs.
* **Linguistic Comparison:** Statistical analysis of perplexity and sentence complexity across different model versions using KDE plots.
